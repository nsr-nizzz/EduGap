# EduGap Frontend

Frontend EduGap dikembangkan menggunakan React.js dan Vite.

## Persyaratan
- Node.js dan npm sudah terinstal.

## Cara Menjalankan

1. Masuk ke direktori frontend:

   ```bash
   cd frontend
   ```

2. Instal dependencies:

   ```bash
   npm install
   ```

3. Jalankan development server:

   ```bash
   npm run dev
   ```

4. Buka URL yang muncul di terminal, biasanya `http://localhost:5173`.

## Build Production

```bash
npm run build
```

Hasil build tersedia di folder `dist/`.
